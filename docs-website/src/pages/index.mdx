<Feature visual={<BenchDemo />}>

## Every review on one bench

diffx opens on **Reviews**: each branch and pull request with changes,
newest activity first. **Needs attention** collects what is new or
updated since you last looked, including work your agents just pushed. Move
with ↑ and ↓, peek with Space, open with Enter.

[Reviewing changes](reviewing-changes.md)

</Feature>

<Feature visual={<GitHubDemo />}>

## Pull requests arrive on their own

Connect GitHub on a diffx server and follow repositories. Their open pull
requests, drafts included, appear on the bench beside your machines' reviews
and refresh from GitHub events.

[GitHub pull requests](github-pull-requests.md)

</Feature>

<Feature visual={<CommentsDemo />}>

## Comment on the lines that need work

Comment on any line or file. Comments and reviewed marks carry across new
snapshots, re-anchor to code that moved, and copy out as agent-ready XML.

[Comments and reviewed marks](reviewing-changes.md)

</Feature>

<Feature visual={<AgentsDemo />}>

## Let agents address the feedback

Connect Claude Code, Codex, Cursor or OpenCode to diffx over MCP. The agent
finds the open threads, fixes each concern, replies with what changed and
resolves it. The review shows every reply as it lands.

[MCP](mcp.md)

</Feature>
