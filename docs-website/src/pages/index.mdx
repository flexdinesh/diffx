# Introduction

diffx opens your Git changes as a readable diff in the browser, keeps your
review comments, and turns them into instructions a coding agent can act on.

## How diffx fits together

Changes reach a diffx server from three sources. You review them on one bench,
and agents pick up what you left.

:::note
**Using a coding agent?** Point it at your server's MCP endpoint and it can
read, reply to and resolve review feedback. Clients sign in through OAuth.

```sh
claude mcp add --transport http diffx https://HOST/mcp
```
