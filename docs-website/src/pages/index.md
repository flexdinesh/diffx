# diffx

Review Git changes in your browser with diffx. Read diffs, mark files reviewed,
and leave comments without changing your working tree or index.

## Start here

[Get started](getting-started.md) with installation and your first local review.

## Your review workflow

- Compare branch changes, staged changes, and unstaged changes.
- Review a captured snapshot at your own pace.
- Keep comments and review progress across restarts.
